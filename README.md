# Clipboard history

Encrypted clipboard history for Windows.

## Installation

```sh
git clone https://github.com/P4suta/clipvault.git
cd clipvault
mise trust
mise install
mise x -- just bootstrap
```

## Usage

```sh
mise x -- just run
```
